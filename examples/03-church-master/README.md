## Build

```bash
python3 -m sfx sfx/cues/church.py                             # music + sfx → public/church.wav
npx remotion render ChurchMaster out/church-silent.mp4
ffmpeg -y -i out/church-silent.mp4 -i public/church.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -movflags +faststart -shortest out/church-master.mp4
```

Render with nothing else running on the machine. On a 4-core, memory-capped container, a parallel render once left 28 frames half-captured (only the top strip drawn). Scan for isolated bad frames after every full render, re-render any you find with `remotion still`, and overlay them back in matching the master's full-range BT.601 colour.

`public/church/intro.mp4` and `intro-bg.mp4` are the BookLaunch render re-encoded to 30 fps (sharp, and pre-blurred for the background):

```bash
ffmpeg -i out/book-silent.mp4 -vf "fps=30,scale=1920:-2,crop=1920:1080,boxblur=30:3,eq=brightness=-0.18:saturation=1.2" -an public/church/intro-bg.mp4
ffmpeg -i out/book-silent.mp4 -vf "fps=30,scale=608:1080" -an public/church/intro.mp4
```

## Assets

- **Cover:** the original front-cover file (`public/book/cover.jpg`), also used in the social cut.
- **Author portrait:** `public/church/author.jpg`, shown in shot 14.
- **Acextic:** sponsor credit, "Presented by" plus the logo, in shot 01 (from 0:04) and on the purchase slate; small corner mark in between.
- **QR code:** supplied and scan-tested; it opens `https://www.amazon.com/dp/B0HF8W6QNV`.
- **Voiceover:** none by design; the narration is burned in as captions and Godfrey speaks live afterwards.
- **Music:** generated by the sfx engine, so it's original and needs no licence.
